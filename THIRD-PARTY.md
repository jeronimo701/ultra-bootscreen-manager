# Сторонние компоненты и материалы

- libnx 4.12.0 — Switch runtime/API, статически используется в NRO. ISC-подобная лицензия: [полный текст](licenses/libnx-LICENSE.md), [исходники версии](https://github.com/switchbrew/libnx/tree/v4.12.0).
- devkitA64 GCC 16.1.0 и switch-tools 1.13.1 — инструменты сборки devkitPro, не включены в репозиторий или релиз. Стандартные библиотеки и runtime из toolchain сохраняют собственные лицензии; GCC runtime имеет отдельное исключение, не лицензию на приложение: [GCC Runtime Library Exception](https://www.gnu.org/licenses/gcc-exception-3.1.html). [devkitPro](https://devkitpro.org/).
- `romfs/font.bin` — растровый атлас символов, генерируется `make-font.ps1` через System.Drawing из системного Consolas. Сам файл шрифта Consolas не распространяется. Для воспроизведения нужен установленный шрифт; права на шрифт не передаются приложением.
- Встроенные заставки и оригинальная заставка UltraNX сохранены из предоставленного автором проекта без изменения. Названия, персонажи и товарные знаки не означают официальную связь с их правообладателями; отдельная свободная лицензия на изображения не назначается.
- Иконка NRO — стандартная иконка из установленного libnx, добавляется инструментом elf2nro.

Эта справка не меняет лицензии зависимостей и не назначает новую лицензию всему проекту.
